# SyncHub AV Pipeline

Дипломный проект. Веб-платформа для синхронизации работы съёмочной группы: режиссёры, костюмеры, визажисты, монтажёры работают в едином пространстве.

**Стек:** React 18 + TypeScript + Vite (клиент), Express 4 + JSON-файл (сервер).

---

## Быстрый старт

### Сервер
```bash
cd server
npm install
npm run dev
```
Запускается на `http://localhost:5001`

### Клиент
```bash
cd client
npm install
npm run dev
```
Открывается на `http://localhost:5173`

## Возможности

### Аутентификация и безопасность
- Регистрация и вход по никнейму + пароль
- Пароли хранятся в виде хеша (`crypto.scryptSync` + случайная соль), не в открытом виде
- Сессии с временем жизни 30 дней; истёкшие автоматически удаляются при старте сервера
- Защита от брутфорса: не более 20 попыток за 15 минут на `/api/auth`
- Лимит запросов на API: 120 запросов в минуту
- HTTP-заголовки безопасности через `helmet`
- Валидация никнейма при регистрации: только латиница, цифры и `_`, длина 3–30 символов

### Офлайн-режим
- Если сервер недоступен, приложение автоматически входит в офлайн-режим с кешированными данными пользователя
- Внизу экрана появляется жёлтый баннер: *«Офлайн-режим — изменения сохраняются локально»*
- На мобильной версии баннер корректно располагается над нижней навигацией
- При восстановлении соединения режим снимается автоматически

### Проекты и разделы
Каждый проект содержит 5 вкладок:

#### Режиссёр (Сценарий)
- Текстовый редактор сценария с корректным направлением текста (LTR)
- Фиксированный режим редактирования

#### Монтажёр (Таймлайн)
- Визуальная временная шкала с маркерами
- Добавление, редактирование и удаление маркеров по временным меткам
- На мобильной версии блок предпросмотра видео отображается первым

#### Костюмер
- Силуэт человеческой фигуры с интерактивными маркерами
- Маркеры отображаются в виде пронумерованных цветных кружков
- Зоны тела с подписями: Голова / Плечи / Торс / Бёдра / Ноги / Стопы
- Поддержка нескольких силуэтов (персонажей); при удалении силуэта удаляются его маркеры; удаление последнего заблокировано
- Карточки маркеров: цветная метка, зона тела, имя персонажа, описание
- Пустое состояние с подсказкой, когда маркеров нет

#### Визажист
- Детальная иллюстрация лица (голова, уши, брови, глаза с радужкой, нос, губы, подбородок)
- Зоны лица с подписями: Лоб / Глаза / Нос / Губы / Подбородок
- Те же интерактивные маркеры, что и у костюмера

#### Звукорежиссёр
- Список звуковых треков и меток

### Профиль и настройки
- Редактирование имени, фамилии, никнейма, роли, аватара (эмодзи), даты рождения, пола
- Смена пароля с подтверждением
- Страница настроек с переключением темы и языка

### Интернационализация (i18n)
- Три языка интерфейса: **Русский**, **English**, **中文**
- Переключатель языка в шапке и в настройках
- Переведены все вкладки, кнопки, подсказки, зоны тела, сообщения об ошибках и офлайн-баннер

### Тема оформления
- Тёмная и светлая тема
- Переключатель в шапке
- CSS custom properties для всех цветов — тема меняется без перезагрузки
- SVG-иконки адаптируются к теме через CSS `filter`

### Мобильная версия
- Нижняя панель навигации с актив-индикатором (акцентная линия)
- На странице проекта — горизонтальная полоса вкладок вверху с цветовым акцентом каждого раздела
- На странице проекта панель можно свернуть/развернуть; на остальных страницах она всегда развёрнута
- Убран горизонтальный скролл на мобиле, блоки перераспределены по приоритету
- Все страницы (Dashboard, Profile, Settings, Help) адаптированы под узкие экраны

### UI-компоненты
- **Toast-уведомления** с анимацией появления (slide + scale) и исчезновения, кнопкой закрытия `×`; разные таймеры: успех 3 с, инфо 4 с, ошибка 6 с
- **ErrorBoundary** — перехватывает ошибки рендера, показывает экран восстановления
- **Modal** — универсальное модальное окно
- **Hint-система** — всплывающие подсказки по интерфейсу
- **Sidebar** с логотипом, навигацией и аватаром пользователя
- **Шапка** с иконками темы, языка, профиля

## Технические детали

### Клиент
- `React 18` + `TypeScript` + `Vite 5`
- Маршрутизация: `react-router-dom v6`
- Состояние: Context API (`AuthContext`, `ToastContext`, `I18nContext`, `HintContext`)
- Стили: чистый CSS с custom properties (без UI-фреймворков)
- SVG-иконки inline и в `<img>` с `filter: var(--icon-filter)` для адаптации к теме

### Сервер
- `Express 4` с REST API
- `helmet` — заголовки безопасности
- `express-rate-limit` — ограничение запросов
- `crypto` (встроенный Node.js) — хеширование паролей
- База данных: `server/data/db.json` (JSON-файл, без внешних СУБД)
- Порт: `5001` (5000 занят AirPlay на macOS)
