# SyncHub AV Pipeline

Дипломный проект. Веб-платформа для координации работы съёмочной группы — режиссёры, сценаристы, костюмеры, визажисты, монтажёры и звукорежиссёры работают в едином пространстве.

**Стек:** React 18 + TypeScript + Vite (клиент), Express 4 + JSON-файл (сервер).

![CI](https://github.com/Whytenko/SyncHub-AV-Pipeline/actions/workflows/ci.yml/badge.svg)

---

## Быстрый старт

### Сервер
```bash
cd server
npm install
npm run dev
```
Запускается на `http://localhost:5001`

### Клиент
```bash
cd client
npm install
npm run dev
```
Открывается на `http://localhost:5173`

## Возможности

### Аутентификация и безопасность
- Регистрация и вход по никнейму + пароль
- Пароли хранятся в виде хеша (`crypto.scryptSync` + случайная соль)
- Сессии с TTL 30 дней; истёкшие автоматически удаляются при старте сервера
- Защита от брутфорса: не более 20 попыток за 15 минут на `/api/auth`
- Лимит запросов на API: 120 запросов в минуту
- HTTP-заголовки безопасности через `helmet`
- Атомарная запись БД: `.tmp` → `rename` (защита от повреждения при сбое)
- Автоматический бэкап базы каждые 5 минут

### Офлайн-режим
- Если сервер недоступен, приложение входит в офлайн-режим с кешированными данными
- Жёлтый баннер «Офлайн-режим» внизу экрана
- При восстановлении соединения режим снимается автоматически

## Вкладки проекта

### 📜 Сценарий
- Загрузка файла сценария (PDF, Word, PNG, JPG) с drag-and-drop
- Большая форма параметров производства: актёрский состав, масштаб, эффекты, транспорт, камера, звук, жанр, риски, концепция
- Параметры влияют на другие вкладки (количество локаций → раскадровка, актёры → визаж/костюмы)

### 🎬 Режиссёрская
- **Раскадровка** (storyboard): таблица «локации × кадры» с редактором ячеек
  - Каждая ячейка: изображение, тип плана (крупный, средний…), описание, хронометраж
  - Хронометраж-бар: суммирует секунды по всем кадрам, предупреждает о превышении длины таймлайна
- Параметры таймлайна (длительность в секундах или формате М:СС)
- Заметки режиссёра с кнопкой «Поделиться»

### 👗 Костюмер
- **Двухпанельный интерфейс**: список образов (слева) + детальный вид (справа)
- Каждый образ: персонаж, ссылки на сцены, статус (не начато / в работе / готово / утверждено)
- Гардероб: таблица элементов одежды с категорией, цветом, материалом, брендом, способом получения (есть / аренда / купить / сшить), ценой
- Итоговый бюджет образа, цветовая палитра (полоска свотчей)
- Заметки к образу, загрузка референс-фото

### 💄 Визажист
- **Двухпанельный интерфейс**: список гримёрных образов + детальный вид
- Каждый образ: персонаж, сцены, время нанесения (мин), статус
- Продукты по зонам: кожа, глаза, брови, губы, скулы, контур, шея
  - Каждый продукт: зона, название, цвет (color picker), техника нанесения
- Особенности кожи / аллергии, референс-фото

### ✂️ Монтажёр
- Медиатека с типами аудио/видео и мета-данными
- Предпросмотр выбранного файла с прогресс-баром (синхронизирован с таймлайном)
- Список документов с предпросмотром
- Комментарии к монтажу: добавление, ответ, пометка «решено / не решено»

### 🎵 Звукорежиссёр
- Звуковые метки привязаны к позиции на таймлайне
- Клик на метку открывает детали в модале таймлайна
- Комментарии к звуку

### 📋 Менеджер
- **Канбан-доска** (6 колонок: К выполнению / В работе / На проверке / Утверждено / Правки / Заблокировано)
  - Drag-and-drop между колонками для смены статуса
  - Drag-and-drop внутри колонки для сортировки
- **Список-вид** с фильтрами по статусу и отделу
- Карточка задачи: приоритет (цветная точка), описание, отдел (цвет вкладки), исполнитель, дедлайн
  - Дедлайн: жёлтый (≤ 3 дней), красный (просрочено)
- **Здоровье проекта**: прогресс-бар + процент одобренных задач по каждому отделу; красный — если есть заблокированные
- Сводка статусов (пилюли с количеством задач)

### Таймлайн (общий для всех вкладок)
- Визуальная шкала с текущей позицией (scrub-bar)
- Маркеры разных цветов и вкладок
- Воспроизведение/пауза, клик для перемотки
- Маркеры отображаются в соответствующих вкладках (звук → вкладка Звук и т.д.)

## Технические детали

### Клиент
- React 18 + TypeScript + Vite 5
- Маршрутизация: `react-router-dom v6`
- Состояние: Context API
- Стили: CSS custom properties (без UI-фреймворков)
- Иконки: `lucide-react`

### Сервер
- Express 4 + REST API
- `helmet` — заголовки безопасности
- `express-rate-limit` — лимиты запросов
- `crypto` — хеширование паролей (scrypt)
- База данных: `server/data/db.json`
- Порт: `5001`
