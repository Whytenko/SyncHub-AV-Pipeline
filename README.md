# SyncHub AV Pipeline
Проект для дипломной работы. Клиент на React + Vite, сервер на Express с локальным JSON-хранилищем.

## Быстрый старт
1) Сервер:
```
cd server
npm install
npm run dev
```

2) Клиент:
```
cd client
npm install
npm run dev
```

По умолчанию сервер стартует на `http://localhost:5000`, клиент — на `http://localhost:5173`.

## Демо-доступ
После первого запуска автоматически создается демо-пользователь:
- Никнейм: `demo`
- Пароль: `demo1234`

## Структура
- `client/` — интерфейс SyncHub
- `server/` — API, хранение в `server/data/db.json`

## Нововведения
- Мобильная нижняя панель управления переработана: порядок кнопок обновлен, активный экран подсвечивается акцентной линией.
- Свернуть/развернуть нижнюю панель можно только на странице проекта. На остальных мобильных страницах она всегда раскрыта как основная навигация.
- На странице проекта добавлена фиксированная верхняя панель разделов для мобильной версии. Активный раздел выделяется акцентной линией в цвет маркеров раздела.
- Улучшена мобильная адаптация страницы проекта: убран горизонтальный скролл, перераспределены блоки по приоритету, упрощена структура контента.
- Для разделов `Костюмер` и `Визажист` реализованы общие силуэты людей (desktop + mobile): можно добавлять и удалять людей, а маркеры привязываются к конкретному силуэту.
- При удалении силуэта удаляются привязанные к нему маркеры, удаление последнего силуэта заблокировано.
- В разделе `Монтажер` на мобильной версии сначала показывается блок предпросмотра видео, затем медиатека.
- Исправлен ввод в редакторе сценария: нормализована направленность текста (LTR), убраны скрытые bidi-символы, из-за которых текст печатался справа налево.
