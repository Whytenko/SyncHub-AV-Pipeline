# Roadmap

Что уже работает, что я делаю прямо сейчас, и что лежит в идеях. Список не финальный — я добавляю и убираю пункты по мере того, как сам пользуюсь приложением.

Помечал так: `[x]` готово, `[~]` в работе, `[ ]` буду делать, `[?]` пока думаю.

## Уже работает

### Фундамент
- [x] Express API на Node 20, PostgreSQL 16 в качестве основной БД
- [x] React 18 + TypeScript + Vite на клиенте
- [x] Регистрация и логин через email + пароль, сессии в БД
- [x] Семь вкладок по отделам (Сценарий, Режиссёр, Костюмы, Визаж, Монтаж, Звук, Менеджер)
- [x] Пять фаз производства с условиями перехода
- [x] Раскадровка, привязанная к сценам (а не к локациям, как было в прошлых версиях)
- [x] Канбан-доска задач с drag-and-drop
- [x] Календарь съёмочных дней
- [x] Загрузка медиа и документов (multer + диск)
- [x] Swagger UI на `/api/docs`
- [x] GitHub Actions: typecheck + сборка + базовые тесты
- [x] Тёмная и светлая темы
- [x] Три языка интерфейса (RU/EN/ZH)
- [x] Мобильная вёрстка с нижней навигацией

### Что я добавил недавно
- [x] **Музыкальный таймлайн.** Звукарь грузит трек, режиссёр расставляет кадры раскадровки на временной шкале. Сделано для своих клипов — но и для рекламы тоже подходит.
- [x] **Выбор типа проекта** (короткий метр / клип / рекламный ролик / документальный). От типа зависят доступные вкладки и поведение таймлайна.
- [x] **Соответствие раскадровке у монтажёра.** На каждый кадр режиссёрской раскадровки монтажёр кладёт скриншот из готовой склейки. Команда видит прогресс кадр-в-кадр.
- [x] **FramePairViewer.** Кликнул по паре «раскадровка → шот» — открылась модалка с двумя изображениями, описанием, навигацией стрелками.
- [x] **FilePreview.** Универсальный просмотрщик PDF/DOCX/TXT/изображений. Кликнул по файлу — открылся в iframe или в `<pre>`. Не надо скачивать.
- [x] **ImageLightbox.** Референсы у костюмера и визажиста открываются на весь экран.
- [x] **Per-project роли.** Глобальный «Режиссёр» в профиле не значит, что в чужом проекте я тоже режиссёр. В каждом проекте свой выбор, который владелец может поменять.
- [x] **Portal-модалки.** Все модальные окна теперь рендерятся в `document.body`, а не в дереве компонентов. Никаких сюрпризов с `transform`-предками, центровка всегда по viewport.
- [x] **CSP-обход для `/uploads`.** Снял `Content-Security-Policy` и `X-Frame-Options` с папки загрузок — иначе Chrome не пускает PDF в iframe с другого порта в dev.

## Идеи на дальнюю полку

Это всё, до чего ещё нескоро доберусь, но не хочу забыть.

- **AI-ассистент по сценарию.** Загрузил PDF — получил автоматическую разбивку на сцены с предложением `INT/EXT`, `DAY/NIGHT`, персонажами.
- **Бюджет проекта.** В костюмах уже есть цены, но я хочу видеть суммарную смету с разбивкой по отделам и сравнением план/факт.
- **Production calendar в .ics.** Чтобы съёмочный день можно было закинуть в Google Calendar или Apple Calendar.
- **Интеграция с Frame.io / Vimeo Review.** Чтобы комментарии монтажёра подтягивались сюда.
- **Mobile-app (хотя бы read-only).** На площадке часто нет ноута, а телефон есть всегда.
- **Экспорт проекта в один PDF.** Сценарий + раскадровка + список локаций + контакты команды — то, что обычно раздаётся на площадке в распечатанном виде.
- **Marketplace локаций и подрядчиков.** Это уже совсем другой продукт, но мысль крутится.
- **Версионность сценария** с diff-просмотром. Целтх это умеет, и это удобно.

## Технический долг

Список вещей, которые работают, но я знаю, что они недоделаны:

- В `Project.tsx` около 2500 строк. Я постепенно вытаскиваю части в отдельные хуки и компоненты, но это медленно.
- `validate.js` — один большой файл с одной функцией. Хорошо бы разбить по сущностям (scenes, tasks, outfits...).
- Стили в `Project.css` написаны без БЭМ и без CSS-modules. Чтобы случайно не сломать чужой класс, я добавил префиксы вручную (`craft-*`, `sb-*`, `pair-viewer-*`), но это не системно.
- Нет нормального error-tracking. Sentry бы не помешал.
- Бекап БД делается через `pg_dump` руками. Нужен cron-скрипт.
