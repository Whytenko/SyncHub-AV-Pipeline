Версия для дипломной работы
1
Обзор проекта
SyncHub AV Pipeline — веб-платформа для координации работы съёмочной группы. Режиссёры, костюмеры, визажисты, монтажёры и звукорежиссёры работают в едином цифровом пространстве.
Проект выполнен как дипломная работа с полным циклом разработки: проектирование интерфейса, реализация REST API, клиентская логика, безопасность и адаптация под мобильные устройства.
Технический стек
Клиент
React 18 · TypeScript · Vite 5
Сервер
Node.js · Express 4 · JSON-база
Безопасность
helmet · express-rate-limit · scrypt
Стили
CSS custom properties · без UI-фреймворков
2
Безопасность сервера (v4)
Хеширование паролей. Вместо хранения паролей в открытом виде применяется алгоритм scryptSync (Node.js crypto) со случайной солью 16 байт. Сравнение выполняется через timingSafeEqual для защиты от timing-атак.
Сессии с TTL. Каждая сессия при создании получает поле expiresAt (+30 дней). При каждом запросе проверяется срок действия. При старте сервера все истёкшие сессии автоматически удаляются.
HTTP-заголовки безопасности. Подключён пакет helmet: выставляются заголовки Content-Security-Policy, X-Frame-Options, X-XSS-Protection, Strict-Transport-Security и другие.
Защита от брутфорса. Маршруты аутентификации ограничены: не более 20 попыток за 15 минут с одного IP. Общий API-лимит: 120 запросов в минуту.
Смена порта. Сервер переведён с порта 5000 на 5001: на macOS порт 5000 занят системным сервисом AirPlay Receiver (возвращал HTTP 403, Server: AirTunes), что блокировало API.
Валидация входных данных. Никнейм при регистрации: только латиница, цифры и символ «_», длина от 3 до 30 символов. Пароль: минимум 8 символов + хотя бы одна цифра. Размер тела запроса ограничен 2 МБ.
CORS. Список разрешённых источников вынесен в переменную окружения ALLOWED_ORIGINS, проверяется явно при каждом запросе.
3
Офлайн-режим (v4)
Автоматическое определение сети. AuthContext различает сетевую ошибку (TypeError при fetch) и ошибку API (неверный пароль, 401). При недоступности сервера — офлайн-режим, при ошибке авторизации — сообщение об ошибке.
Локальный кеш. После успешного входа данные пользователя сохраняются в localStorage. При потере сети приложение автоматически использует кешированный профиль с токеном «local».
OfflineBanner. Новый компонент — фиксированный баннер внизу экрана с пульсирующей жёлтой точкой и текстом: «Офлайн-режим — изменения сохраняются локально». На мобиле располагается над нижней панелью навигации.
Корректный выход из системы. При офлайн-режиме logout не делает API-запрос (токен «local»), очищает localStorage и сбрасывает состояние.
4
Визуализация тела и лица (v4)
Вкладка Визажист
Новая иллюстрация лица (face.svg). Специально созданный SVG-рисунок: овал головы, уши, брови, глаза с радужкой, мост носа с ноздрями, губы (верхняя с изгибом, нижняя), намёк на подбородок.
Зоны лица. Вертикальные метки справа от иллюстрации: Лоб / Глаза / Нос / Губы / Подбородок — на низком уровне прозрачности, не перегружают интерфейс.
Адаптация к теме. SVG использует currentColor; изображение адаптируется к тёмной и светлой теме через CSS-переменную --icon-filter.
Вкладка Костюмер
Пронумерованные маркеры. Маркеры теперь отображаются в виде цветных кругов с порядковым номером вместо безымянных квадратов. Каждый круг стилизован под цвет маркера через CSS-переменную --mc.
Зоны тела. Силуэт дополнен шестью текстовыми метками: Голова (4%) / Плечи (22%) / Торс (40%) / Бёдра (60%) / Ноги (78%) / Стопы (94%) — позиционированы абсолютно вдоль силуэта.
Карточки маркеров. Каждая карточка: цветная полоса слева, пронумерованный значок, ярлык зоны тела, имя персонажа, описание. При наведении — подсветка фона.
Пустое состояние. Когда маркеров нет — отображается иконка и поясняющий текст вместо пустого пространства.
5
Интерфейс и уведомления (v4)
Toast-уведомления. Полная переработка: анимация появления (slide справа + scale) и исчезновения (обратная). Кнопка закрытия «×» на каждом уведомлении. Разные таймеры: успех — 3 с, информация — 4 с, ошибка — 6 с.
Состояния кнопок. Задизейбленные кнопки: opacity 0.45, cursor not-allowed. Фокусные кольца через focus-visible для доступности. Спиннер загрузки внутри кнопок.
Tooltips маркеров. Позиционирование исправлено: bottom: calc(100% + 8px) вместо фиксированного top. Добавлена тень и рамка, ограничена максимальная ширина 180px.
6
Мобильная версия (v1–v4)
Нижняя панель навигации. Заменяет боковую панель на мобиле. Порядок кнопок обновлён, активный экран подсвечивается акцентной линией в цвет раздела.
Вкладки проекта. На странице проекта — горизонтальная фиксированная полоса вкладок вверху экрана. Каждая вкладка имеет собственный цветовой акцент. Свернуть/развернуть панель можно только на странице проекта.
Монтажёр на мобиле. Блок предпросмотра видео отображается первым, затем медиатека — в соответствии с приоритетом использования.
Устранён горизонтальный скролл. Перераспределены блоки контента, упрощена структура страницы проекта на узких экранах.
Все страницы адаптированы: Dashboard, Profile, Settings, Help — полная мобильная адаптация с переработанными сетками и отступами.
Силуэты на мобиле. Иллюстрации тела и лица корректно масштабируются, зоны тела уменьшают шрифт до 9px, OfflineBanner располагается над навигационной панелью.
7
Интернационализация (v2–v4)
Три языка интерфейса: Русский, English, 中文 (китайский). Переключатель в шапке и на странице настроек.
Охват переводов: все вкладки проекта, кнопки, ярлыки зон тела (Голова / Shoulders / 头部 и т.д.), подсказки, сообщения об ошибках, офлайн-баннер, пустые состояния.
Реализация через Context API (I18nContext). Смена языка мгновенная, без перезагрузки страницы.
8
Профиль, настройки и навигация (v2–v3)
Профиль пользователя. Редактирование имени, фамилии, никнейма, роли в производстве, аватара (эмодзи), даты рождения, пола. Смена пароля с подтверждением.
Настройки. Переключение тёмной/светлой темы, выбор языка интерфейса. Настройки сохраняются между сессиями.
Боковая панель (Sidebar). Логотип SyncHub, список проектов, аватар и имя пользователя внизу. Скрывается на мобильных устройствах.
Шапка (Header). Иконки быстрого переключения темы, языка, перехода в профиль. Поддержка скрытия на мобиле.
Hint-система. Всплывающие подсказки при первом взаимодействии с элементами интерфейса.
ErrorBoundary. Компонент-страховка: перехватывает ошибки React-рендера, показывает экран восстановления с кнопкой «Перезагрузить».
